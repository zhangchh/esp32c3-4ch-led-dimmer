⓪ 输出级三个关系（看不懂这张图就看这里）

整路功率级只围绕两个节点：节点 A = 12V、节点 B = 灯带负极 = MOSFET 漏极。
· 灯带 2 脚（正） → 节点 A（12V）
· 灯带 1 脚（负） → 节点 B（和 MOSFET 漏极是同一个点）
· 100 nF 电容：一只脚 → 节点 A，另一只脚 → 节点 B（= 跨接在灯带两端）
· MOSFET 源极 → 地；栅极 → PWM（经 220Ω），并有 100kΩ 下拉到地

① 逐路接线清单（按实物说，不用位号）

#元件接法网络

2100 nF 陶瓷（ADC 滤波） 一端 → 该路 ADC 引脚，另一端 → 地（尽量靠近芯片引脚）ADC / GND
3220 Ω 电阻 一端 → 该路 PWM 引脚，另一端 → MOSFET 栅极 GPWM / GATE
4100 kΩ 固定电阻 一端 → MOSFET 栅极，另一端 → 地（栅极下拉，必须有）GATE / GND
5IRLZ44N MOSFET 栅极 G接上面节点；漏极 D → 灯带负极；源极 S → 地GATE / DRAIN / GND
6灯带两芯座 1 脚（−） → MOSFET 漏极；2 脚（+） → 12 VDRAIN / 12V
7100 nF 陶瓷（跨灯带） 一端 → 灯带负极（漏极），另一端 → 灯带正极（12 V），跨接在灯带两端DRAIN / 12V
8470 µF 电解（公共） 正极 → 12 V，负极 → 地（注意极性），尽量靠近灯带接口12V / GND
9开发板 GND 与 12 V 地 必须用一根线把开发板的 GND 和 12 V 的 GND 连起来（共地），否则 PWM 没有参考电平GND
三个必须注意：① 开发板 5V 引脚绝对不能接 12V（板载 LDO 最高 6.5 V，会烧）；② 栅极 100 kΩ 下拉不能省，否则 ESP32 复位 / 烧录时灯带会乱闪；③ 电位器要买 线性(B) 型，软件做 gamma 校正，不要买对数型。

为什么避开 IO2？ ESP32-C3 的 GPIO2 / GPIO8 / GPIO9 是启动模式（strapping）引脚，复位瞬间的电平决定芯片是正常启动还是进下载模式。接了外部电路可能导致烧不进程序。所以 IO2 不用、IO8 是板载 LED、IO9 是 BOOT 按钮，全部避开。

其余引脚怎么用

引脚说明
IO20 / IO21UART0（RX/TX），留给串口调试 / 烧录，别占用
IO8板载蓝色 LED（低电平点亮），不要接外部电路
IO9BOOT 按钮，不要接外部电路
IO2只有实在不够用时才用，且只接输出（接栅极），不要接电位器
IO6 / IO7默认是 JTAG 功能，不开 JTAG 就能当普通 GPIO 用
3V3 引脚给 4 个电位器供电（4 × 0.33 mA = 1.3 mA，随便带）

③ 固件（ESP32-C3 / Arduino 框架）

#include <Arduino.h>

const int POT[4] = {0, 1, 3, 4};      // IO0 IO1 IO3 IO4  (ADC1)
const int PWM[4] = {5, 6, 7, 10};     // IO5 IO6 IO7 IO10 (LEDC)
const int RES  = 4095;                // 12 bit
const float FREQ = 4000.0;            // 恒定 4 kHz

float ema[4];
int  calMin[4] = {0,0,0,0};
int  calMax[4] = {4095,4095,4095,4095};
bool inited = false;

void setup(){
  analogReadResolution(12);
  analogSetAttenuation(ADC_11db);        // 0~3.3V 量程
  for(int i=0;i<4;i++){ ledcSetup(PWM[i], FREQ, 12); ledcAttachPin(PWM[i], PWM[i]); }
}

void loop(){
  for(int i=0;i<4;i++){
    int raw = analogRead(POT[i]);
    ema[i] = inited ? ema[i]*0.75f + raw*0.25f : raw;   // 一阶低通
    float x = (ema[i]-calMin[i]) / (float)(calMax[i]-calMin[i]);
    x = constrain(x, 0.0f, 1.0f);
    float duty = powf(x, 2.2f);                          // gamma 校正
    ledcWrite(PWM[i], (uint32_t)(duty*RES));
  }
  inited = true;
}

标定：首次上电把 4 个旋钮分别转到最小 / 最大，把读到的 raw 写进 calMin[] / calMax[]（存 NVS 更好），即可消掉 ESP32 ADC 的非线性与电位器个体差异。

想加无线：ESP32-C3 自带 WiFi/BLE，做个网页或手机 App 改 calMax[] 和亮度即可，不用改硬件。

⑥ 上电自检

步骤现象 / 判据
1. 只插 USB，不接 12 V板载蓝色 LED 闪烁 = 固件正常
2. 万用表量引脚IO0 / IO1 / IO3 / IO4 电压随旋钮在 0~3.3 V 平滑变化
3. 量 PWM 引脚IO5 / IO6 / IO7 / IO10 应是 0~3.3 V 的方波（有示波器最直观；没有就用一颗 LED 搭个负载看）
4. 接 12 V 前，先确认共地万用表测开发板 GND 与 12 V 负极之间电阻应为 0 Ω
5. 接上灯带灯带随旋钮平滑变暗变亮，最低能完全熄灭
6. 测灯带电流0 ~ 0.83 A 随旋钮变化
如果灯带完全不亮：① 查 MOSFET 栅极有没有 3.3 V 方波；② 查漏源是否接反；③ 查共地；④ 确认灯带正极接的是 12 V 而不是 DRAIN。
