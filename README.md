## 1. 原理图解读

### 1.1 每一路的信号链

```
 10kΩ 电位器                       ESP32-C3                    UCC27524            IRLZ44N        12V 灯带
 ┌──────────┐                     ┌─────────┐
 │ 3V3 ─┤├─ GND                   │         │  IO21/IO7/IO6/IO5
 │       ▲ wiper ──100nF──> IO0/1/3/4 (ADC1)  │        INA(2)/INB(4)   OUTA(7)/OUTB(5)  G
 │       │                        │         │ ────────>│──>│──47Ω──>│
 └───────┘                        └─────────┘         │    │          │  D ──> 灯带 −
                                                              VDD(6)=+12V      │  S ──> GND
                                                              GND(3)=共地      │
                                                              EN(1/8)=+12V     │
```

### 1.2 三条决定固件写法的结论

| 结论 | 原因 | 对固件的影响 |
|---|---|---|
| **占空比 = 亮度，不取反** | UCC27524 是**非反相**栅极驱动器（INA→OUTA、INB→OUTB 直通） | PWM 写 `duty` 而不是 `4095-duty`；0% 全灭、100% 最亮 |
| **UCC27524 只驱动栅极，不承载灯带电流** | 4 A/8 A 栅极驱动器 + IRLZ44N 做功率开关 | MCU 侧无需大电流，LEDC 驱动能力足够 |
| **输出级是低边开关，负极受控** | 源极直连 GND，漏极接灯带负极 | 灯带正极始终接 +12V；断电/关断时灯带不带电 |

### 1.3 两份文档的差异（重要）

`docs/mcu-wiring.html` 描述的是**早期直驱方案**：PWM 经 220Ω 直接进 MOSFET 栅极，
PWM 脚是 IO5/IO6/IO7/IO10，**没有 UCC27524**。

`docs/4-channel-led-pwm-wiring-v3.html`（**已焊接的硬件**）增加了 UCC27524 栅极驱动器：
栅极串阻改为 47Ω，PWM 脚改为 **IO21/IO7/IO6/IO5**。

> 本固件按 **v3** 编写。若你的板子实际是直驱版本，只需改固件顶部
> `kPwmPin[4]` 数组即可（对应 IO5/IO6/IO7/IO10）。

### 1.4 硬件要点速查

- **UCC27524 引脚**：`1=ENA 2=INA 3=GND 4=INB 5=OUTB 6=VDD 7=OUTA 8=ENB`
  - 每颗驱动两路：U6 → CH1/CH2，U7 → CH3/CH4
  - `VDD(6)` 接 **+12V**，`GND(3)` 接**共地**，`ENA(1)/ENB(8)` 接 +12V（内部有上拉，也可悬空）
  - 每颗旁边 100 nF + 4.7 µF 去耦
- **栅极网络**：47Ω 串阻 + **100kΩ 下拉到地**（这个下拉不能省，否则烧录/复位时灯带乱闪）
- **ADC 端**：10kΩ 电位器跨 3V3–GND，wiper 经 100nF 对地接 ADC
- **供电**：ESP32-C3 只由 USB 供电，**绝不接 12V**；但 **必须与 12V 负极共地**

## 2. 引脚对照表

| 通道 | 电位器 wiper → ADC | PWM → UCC27524 | 驱动器 | MOSFET | 灯带 |
|---|---|---|---|---|---|
| CH1 | **IO0** (ADC1_CH0) | **IO21** → U6 INA(pin2) | U6 OUTA(pin7) | Q1 | 灯带 1 |
| CH2 | **IO1** (ADC1_CH1) | **IO7** → U6 INB(pin4) | U6 OUTB(pin5) | Q2 | 灯带 2 |
| CH3 | **IO3** (ADC1_CH3) | **IO6** → U7 INA(pin2) | U7 OUTA(pin7) | Q3 | 灯带 3 |
| CH4 | **IO4** (ADC1_CH4) | **IO5** → U7 INB(pin4) | U7 OUTB(pin5) | Q4 | 灯带 4 |

未使用：IO2（启动脚）、IO8（板载 LED）、IO9（BOOT 按钮）、IO10/IO11（备用）。

## 3. 固件说明

### 3.1 主循环（125 Hz）

```
读 ADC → EMA 低通(0.25) → 按标定区间归一化到 0..1 → gamma 2.2 → 斜率平滑(0.35) → LEDC
```

- **EMA 低通**：抑制电位器接触噪声
- **gamma 2.2**：线性(B 型)电位器 → 人眼感知线性。买**线性 B 型**电位器，不要买对数 A 型
- **斜率平滑**：旋钮快速转动或 ADC 抖动时，亮度平滑跟随，避免频闪
- **死区**：目标占空比 < 2% 直接置 0，保证能真正完全熄灭

### 3.2 关键参数（都在固件顶部，可直接改）

| 参数 | 值 | 说明 |
|---|---|---|
| `kPwmFreqHz` | 4000 Hz | 恒频 PWM。想消除可闻声可改 16000~20000（UCC27524 驱动速度足够） |
| `kPwmResolution` | 12 bit | 4096 级 |
| `kGammaDefault` | 2.20 | 软件 gamma |
| `kAdcEmaAlpha` | 0.25 | ADC 低通 |
| `kDutyEmaAlpha` | 0.35 | 亮度平滑（≈30 ms 时间常数） |
| `kMinOnDuty` | 0.02 | 熄灭死区 |
| `kAdcSatMv` | 2500 mV | 11dB 衰减下 ADC 的线性上限 |

### 3.3 上电行为

1. `setup()` 先把 4 个 PWM 引脚配成**普通输出并拉低**，再挂接 LEDC —— 避免 ESP32 复位期间
   UCC27524 的输入悬空导致 MOSFET 误开
2. 输出初始占空比为 0，灯带不亮
3. 按住 **BOOT 键**上电 → 直接进入标定向导

### Arduino IDE

| 设置 | 值 |
|---|---|
| 开发板 | `ESP32C3 Dev Module` |
| **USB CDC On Boot** | **`Enabled`** ← 必须，见下方说明 |
| Flash Size | 4MB |
| Upload Speed | 921600 |
| 串口监视器波特率 | 115200 |

> 本工程已在 Arduino-ESP32 **3.3.12** + `esp32:esp32:esp32c3:CDCOnBoot=cdc` 下实测编译通过：
> Flash 占用 26%（336 KB），RAM 占用 5%（17 KB）。

打开 `4ch_led_dimmer/4ch_led_dimmer.ino` → 编译 → 用板子上**唯一那个 USB-C 口**烧录。
首次烧录若报 `Failed to connect`，按住 **BOOT** 键再点上传。

> ### ⚠️ 为什么必须开 USB CDC On Boot
> **GPIO21 同时是 CH1 的 PWM 脚和 UART0 的 TX。**
> 若 `USB CDC On Boot = Disabled`，Arduino 的 `Serial` 会占用 GPIO21 去发 UART0，
> 与 CH1 的 PWM 输出互相打架（灯带会乱闪或不受控）。
> 打开 USB CDC 后串口走原生 USB（USB-Serial-JTAG），完全不碰 GPIO21。
>
> * Arduino-ESP32 **3.3.x**：`USB CDC On Boot` **默认就是 `Disabled`**，必须在 Tools 下拉
>   菜单里手动改成 `Enabled`。
> * Arduino-ESP32 **2.x**：同样默认 `Disabled`，需手动改成 `Enabled`。
>
> 固件已适配两个大版本（3.x 用 `ledcAttach(pin,...)` 新 API，2.x 用
> `ledcSetup/ledcAttachPin` 旧 API），无需你改代码。
> 若忘了开 USB CDC，编译时会有一条 `#warning` 提醒你。

### ESP-IDF

代码是标准 Arduino 写法，若你用 ESP-IDF 需要改 `analogReadMilliVolts()` 与 LEDC 初始化，
逻辑部分（`updateChannels()` / 标定）可直接移植。

### 上电后自检清单（照着做一遍，约 5 分钟）

1. **看串口**：插上板子 → 打开串口监视器（**115200**，选**原生 USB** 那个 COM 口，
   名字通常带 "USB JTAG/serial"）→ 应看到：
   ```
   ========== 4ch_led_dimmer ready ==========
   PWM: 4000 Hz / 12 bit   gamma: 2.20
   ```
   没有任何输出 → 回到 §4 检查 **USB CDC On Boot = Enabled**（这是编译期选项，
   改完必须重新编译+烧录）。
2. **跑标定（必做，只做一次）**：输入 `cal` 回车 → 把 4 个旋钮**全部转到最小**回车 →
   **全部转到最大**回车 → 固件打印每路的 min/full 电压并写入 NVS（掉电保持）。
   之后 `cal show` 可复查。
3. **验证旋钮**：逐个转动旋钮，`status` 里对应通道的占空比应 0%→100% 单调变化，
   其余三路不动。
4. **验证输出**：万用表直流档量灯带两端电压 ≈ `占空比 × 12 V`
   （4 kHz PWM，万用表读到的是平均值）；旋钮拧到最小应接近 0 V。
5. **核对供电**：4 路全亮时 12V 侧电流约 **3.3 A**，电源用 **12 V / 5 A**；
   ESP32 的 **GND 必须与 12V 负极共地**，否则 PWM 没有参考电平，灯带会乱亮。

> 烧录后如果旋钮拧到顶仍"不满亮度"，或顶部有一段没反应 → 是 ADC 饱和，见 §7.1。

## 5. 串口命令

打开串口监视器（115200），输入：

| 命令 | 作用 |
|---|---|
| `status` | 显示每路的 wiper 电压 / 旋钮位置 / 实际占空比 |
| `cal` | **两步标定向导**（最小 → 最大），结果写入 NVS |
| `cal min` / `cal max` | 只采集最小值 / 最大值 |
| `cal show` | 查看当前标定值 |
| `cal reset` | 恢复默认标定 |
| `off` / `on` | 强制全灭 / 恢复由旋钮控制（调试用） |
| `gamma <x>` | 临时改 gamma（1.0~5.0），重启后恢复默认 |
| `help` | 命令列表 |

## 6. 标定流程

标定的作用：消除 **ESP32 ADC 的非线性**、**电位器个体差异**，并确定**满量程点**。

1. 烧录后打开串口监视器，输入 `cal`（或按住 BOOT 上电）
2. 把 4 个旋钮**全部转到最小**，按回车 → 固件采样 2.4 s 记录各路最小电压
3. 把 4 个旋钮**全部转到最大**，按回车 → 固件采样记录各路满量程电压
4. 标定值写入 NVS，掉电保持；之后 `cal show` 可复查

## 7. 已知限制与硬件改进建议

### 7.1 ADC 饱和 → 电位器顶部约 1/4 行程是死区

ESP32-C3 的 ADC 在 **11dB** 衰减下线性范围只有 **0 ~ 2.5 V**，而电位器跨接 3.3V。
所以 wiper 超过 2.5 V 后读数封顶，旋钮顶部约 `1 - 2.5/3.3 = 24%` 的行程不再改变亮度。

- **当前固件的做法**：把饱和点当作 100% 亮度点 → 旋钮拧到约 75% 就已经全亮，
  再往上是一段死区。功能正确，只是旋钮行程没有用满。
- **硬件改法（可选，一次性改 4 处）**：在每个电位器的 **3V3 端串一个 3.3 kΩ 电阻**。
  电位器顶端电压变为 `3.3 × 10/(10+3.3) ≈ 2.48 V`，正好落在 ADC 线性区内，
  **全程 0~100% 无死区**。改完后重新执行一次 `cal` 即可。
- 千万不要换成对数(A 型)电位器。

### 7.2 GPIO21 上电瞬间可能闪一下

ESP32-C3 的 ROM 启动日志默认从 UART0 TX（GPIO21）输出，复位瞬间 GPIO21 上是随机电平，
CH1 可能轻微闪动一下（栅极 100kΩ 下拉会把大部分时间压住）。属于正常现象，不影响使用。

### 7.3 建议加的两处小改动

- **UCC27524 的 INA/INB 各加一个 10 kΩ 下拉到地**：ESP32 掉电而 12V 还在时，
  GPIO 变高阻，驱动输入可能悬空导致 MOSFET 半开。10kΩ × 4 = 4 颗电阻。
- **12V 入口加 470 µF/25V 电解电容 + 3A 保险丝**：4 路同时满载时总电流约 3.3 A。

### 7.4 功耗核对

| 项目 | 数值 |
|---|---|
| 单路电流 | 0.83 A（10 W/m ÷ 12 V，1 m 灯带） |
| 4 路总电流 | 3.33 A → 电源选 **12 V / 5 A** |
| MOSFET 损耗 | `0.83² × 0.09 Ω ≈ 62 mW` → **不需要散热片** |

## 8. 故障排查

| 现象 | 排查方向 |
|---|---|
| 灯带完全不亮 | ① 12V 是否到位；② **开发板 GND 是否与 12V 负极共地**（万用测阻值应为 0Ω）；③ MOSFET 漏源是否接反；④ 灯带正极是否误接到 DRAIN |
| 某一路不亮 | 该路 PWM 脚到 UCC27524 IN 的连线；UCC27524 对应输出 OUT 是否有 0~12V 方波 |
| 亮度乱跳 / 灯带闪 | 100kΩ 栅极下拉是否漏焊；12V 供电压降；灯带与电源线是否过长过细 |
| 旋钮拧到底还是不满亮度 | 正常，见 §7.1（ADC 2.5V 饱和） |
| 旋钮有"死行程" | 电位器不是线性 B 型，或没做标定（跑一次 `cal`） |
| 上电瞬间灯带乱闪 | 栅极 100kΩ 下拉缺失；IO 输入悬空（按 §7.3 补 10kΩ 下拉） |
| 串口无输出 / 端口是 UART0 | Tools → **USB CDC On Boot = Enabled**（见 §4） |
| 串口输出乱码 | 波特率不是 115200 |

## 9. 电气安全

- 开发板 **5V 引脚绝对不能接 12V**（板载 LDO 最高 ~6.5 V，会烧）
- 12V 与 3V3 **必须共地**，否则 PWM 没有参考电平，灯带会乱亮
- 12V 主回路加 **3A 保险丝**
- 灯带长度按每米 0.83 A 核算，线径与电源留余量
- 功率级与低压 MCU 走线分开，避免大电流回路串过 ADC 地线

bash 4ch_led_dimmer/test/run_test.sh

ADC 饱和钳位、亮度单调性、`off/on`、`cal min/max` 标定流程、未知命令容错。

> 测试用的 Arduino API 是 mock 的，**不能替代真机验证**：它验证的是算法与引脚映射，
> 不是 ESP32-C3 的真实 ADC 线性度和 LEDC 波形。真机请按 §4 的「上电后自检清单」确认。
